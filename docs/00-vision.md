# Vision & Positionnement

## Pourquoi cette architecture ?
- **Astro + React** : capitalise sur un rendu statique ultra-rapide tout en injectant des îlots React pour les parties dynamiques (console admin, formulaires).
- **Supabase** : fournit un backend-as-a-service complet (Postgres, authentification, stockage) sans gérer d’infrastructure lourde.
- **AWS + Terraform + Kubernetes** : garantit une plateforme cloud industrielle, reproductible et prête à scaler.
- **Observabilité native** : Prometheus, Grafana et Elastic permettent d’anticiper et résoudre rapidement les problèmes.

## Comment le projet reflète une agence premium ?
- Branding inspiré des dégradés midnight/indigo/cyan.
- Templates Astro prêts pour études de cas + blog.
- Pipeline CI/CD et IaC livrés pour illustrer la maturité technique.
